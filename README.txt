FREE HOSTING OPTION:
1. Create a free GitHub account.
2. Create a public repository named: yourusername.github.io
3. Upload index.html and logo.jpg.
4. Open Settings -> Pages and publish from the main branch.
5. Your free website will be: https://yourusername.github.io

CUSTOM DOMAIN:
Buy a domain such as accurainternational.com and connect it to GitHub Pages.
GitHub Pages supports custom domains.

Replace the placeholder phone, WhatsApp and email details in index.html before publishing.
